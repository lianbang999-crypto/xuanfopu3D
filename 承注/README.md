# 承注 · 體例

《選佛譜》是一部**帶繼承指令的書**。蕅益大師於逐位譜曰之中，親手寫下「下皆准知」「下五位准知」「下諸位中准此應知」「次位那佛准此應知」「如常可知」「餘如上說」等**帶作用域的授權語**——凡後位不復重述升降緣由者，皆已由前文明文委派。

故補全 220 位 × 21 相 ＝ 4620 格之義理，其主體工作不是令 AI 生成，而是**把大師寫下的繼承指令逐條讀懂、核定其作用域**。

## 一 · 手工核的對象是「規則」，不是「格」

人工核定的是**繼承指令規則**（門十二共 15 條，條條繫原文行號）；由規則展開為逐格緣由，是機械動作，交 `expand.mjs`。

理由：人去手抄 1092 格，錯率遠高於核 15 條規則；而機械展開可復算、可回查、規則一經修訂即時重算全門。

**繼承的是「緣由」，不是「去向」。** 去向以 `xuanfopu-h5/data/positions.json` 判定表為準——該表 M0 已雙錄互證（219 位 × 21 相 ＝ 4599 格全同），本工程不動判定，只補緣由。

## 二 · 展開器同時是校驗器

`expand.mjs` 三道校驗，三者皆零方可入庫：

1. 規則判「不行」而判定表列了去向 → 衝突
2. 規則判「行」而判定表未列 → 衝突
3. 判定表有格而無任何規則覆蓋 → 漏

第 2 條尤要緊：它專治「作用域畫寬」。門十二初稿即由此逼出 7 處作用域過寬（那謨、阿陀兩相的省稱區間），全屬人工誤判，已改。

## 三 · 四級標色

| 級 | 義 | 前臺呈現 |
|---|---|---|
| **直說** | 本位譜曰逐相明說 | 標「譜曰」＋卷次行號 |
| **承注** | 前位譜曰明文委派（文中授權語） | 標「承某位譜曰」＋授權語＋雙方行號 |
| **攜帶** | 本組未另立說，承他組同名條（體例） | 標「依本譜通例」＋來源 |
| **通則** | 卷一相雜不行通則（出處＝門一見取位 g01-04 L57） | 標「卷一通則」 |

另有**推演**一層：譜曰未逐相明說、由本譜內證推得者。**不加裁定標籤，也不加「譜中未明說」之類免責句**——直陳緣由，把所據原文逐條掛在 `[n]` 標記上即可。讀者點開角標即見原文與出處，是否直說、一看便知；如實靠引文本身，不靠免責話術。

推演格的答語與所據原文，全部列在 `推演記.md`，供智能體直接徵引。

**通義外延**（門十三立）：所據是原文中的**普遍命題**（如「地法尊勝。故須阿佛。乃能登之」「圓人善超。一生能頓入故」）。成立須嚴設三條件，缺一不可：①所據句中不含「此位」「本位」等限定語；②以下諸位判定格局與源位同構，**且可由判定表機械驗證**（非人眼認定）；③源位與所及諸位間無相反明文。三條有缺即降為推演。

**跨門承注之限**：本門自有依據者不假外求。門十四上三淨土之贈掷，雖與門十三格局全同，仍依本門「上三淨土皆但總列一名而已」為據，**不援門十三**——二門所被之機不同（一是圓教自修位次，一是淨土橫超），義理不應混。惟門十五之授權語確在門十三（妙覺極果不列因位），係本門實無其文，屬例外。

**「不行」與「無行法」必須分判**（門十五立）：前者此路不通而別有可行之路，後者本無路可言（究竟果位）。資料層以 `verdict` 分判，前臺文案亦當有別——若混為一談，即以終局為障礙，義理全乖。

## 三之一 · 統一契約：每格 ＝ 答 ＋ 引

`expanded.json` 每一格皆為同一形狀，智能體一套渲染通吃：

```json
{ "verdict": "行 | 不行 | 無行法",
  "答": "……緣由之句，內含 [n] 標記……",
  "引": [ { "n":1, "text":"逐字原文", "ref":"《選佛譜》卷第六・初發心住・L57",
            "pos":"g12-11", "juan":6, "line":57 } ],
  "level": "直說 | 承注 | 攜帶 | 通則 | 推演",
  "ruleId": "R12-5" }
```

- **直說／承注／攜帶／通則**格：`答` 即原文本身，`引` 一條。
- **推演**格：`答` 是合成句，`引` 二至三條，逐句各繫出處。
- `level` **僅供審計與校驗，不出前臺**——前臺只呈 `答` 與可點開的 `引`。

## 三之二 · 「等N」省稱的三種用法

全譜省稱有三式，不可混用（門十二、十三各踩過一次）：

1. **等後連續**：「那那等三」＝那那 那謨 謨謨（依序順取）。**門一用二十一序**（「阿彌至謨佛」得九相），餘門用十五序——二序同源，十五序即二十一序去相雜六相之所餘
2. **同缺展開**：「阿阿等不行」無數詞——依譜表實際同缺者展開（門十四 g14-03 得六相）
3. **同判展開**：「阿陀等四」＝阿陀 彌陀 陀陀 **謨佛**（四相同判「圓向贈一」，那佛在序中居間而別判，故不入）

**且省稱組內各相的存廢邊界未必相同**——「那那等三」之那謨止於第 5 位，其餘二相延至第 10／16 位；「阿陀等三」之阿陀止於第 46 位，其餘二相延至第 50 位。**不得以組為單位一展到底**，須逐相各核。此則由門十二嚴格校驗逼出，是本工程最要緊的一條教訓。

### 各門判「不行」之理不可互套

- **門一發始因地**：因地既異，不行之理亦異——二十一位判法無一雷同（不肯修／所不務／能伏見愛／暫不行）
- **門三四種惡趣**：壽長無善事可修——阿鼻獄十一相不行，「一墮難出。劫數長遠」
- **門五色無色天**：耽定不修散善——四空「唯耽暗定」；有頂「更無可進」
- **門六生善滅惡**：正作佛事時惑不現行——「正聽法時。對治見思。令不現起」「既結壇儀。不起惑業」
- **門七增上戒學**：得無漏戒永無退轉——三惡相自「住毗尼而不動」起不行
- **門八增上定學**：修無漏觀必捨欲纏——三惡相自九想觀起不行
- **門十藏教**：不起惡故——三惡相自忍位起不行；末位「**可贈而不可行**」
- **門十一通教**：一切煩惱不復現前——三惡相自八人地起不行；門旨在「**被接**」
- **門十二別教**：惑業次第斷——三惡相分三道邊界（第 5／10／16 位）次第退場
- **門十三圓教**：一次收盡——三惡相自圓十信起全門不行，合「圓人善超」
- **門十四淨土**：華開時節——不論惑業，只論蓮華開敷遲速

**「伏」與「斷」之判貫穿全譜**：門一四禪四等四空出世福業四位不行三惡相，是「暫伏」（g01-19 L117 問答明文）；門十三圓十信不行三惡相，是「任運先斷」。伏者猶現起，斷者不復現。

### 二處跨門授權（全譜僅此二處）

1. **門十五承門十三**——妙覺極果無譜表之由，在門十三總說「即位次而非位次。不應列入因位中矣」（g13 L229）
2. **門十一承門十**——十佛地末繫「**餘如藏教佛果中說**」（g11-10 L165），承 g10-16「可贈而不可行」

### 二處二十一相全行（相雜六相俱得起手）

1. **門一全門**——「此是發始因地。隨擲所現。必皆起手」（g01-04 L57）
2. **門四南贍部洲**——「此洲之人。根性猛利。易墜易升。故隨擲所現。無不行者」（g04-04 L111）
