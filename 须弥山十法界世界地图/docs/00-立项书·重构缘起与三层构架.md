# 立项书 · 重构缘起与三层构架

> 2026-07-18 · 发起人指示：旧架构推倒，新开独立项目；美术、构架、交互重新思考；
> **所有设计以佛教经典原文为准（从 CBETA 查证）**；旧工程三份文档未经论证，仅作线索。

---

## 一、为什么推倒重来

旧工程（《十法界须弥山世界》，makeplay v42 复刻）的世界模型有三个结构性问题：

1. **经证不实**：102 条「经证」大多是【概述】（义理转述），非逐字原文；且无机器核证，
   文字是否与 CBETA 一致、出处行号是否真实，全凭编写时的自觉——这达不到「不妄语」的标准。
2. **三种空间混为一谈**：经论明文定位的（须弥、四洲、诸天）、经明言无方所的（无色界、四圣）、
   游戏行棋需要的（220 位星域锚点），在旧模型里同挂一张「星图」，界限含糊。
3. **文档与数据双源**：设计书写一套、数据存一套，改动后互相漂移，无从对账。

## 二、新构架：三层分离

```
┌─────────────────────────────────────────────┐
│ 呈现层  map/index.html（立轴地图）· 未来 3D  │  ← 只读模型层
├─────────────────────────────────────────────┤
│ 模型层  data/world.json（唯一数据源）        │  ← 层域/节点/经证引文
├─────────────────────────────────────────────┤
│ 语料层  cbeta/text/*.txt（带页行号）         │  ← CBETA 原文，只增不改
└─────────────────────────────────────────────┘
        ↑ scripts/verify-claims.mjs 把模型层逐条钉在语料层上（逐字子串 + 行号一致）
        ↑ scripts/gen-gazetteer.mjs 由模型层单源生成文档，杜绝双源漂移
```

**核证闭环**：任何人改 `world.json`，跑 `verify-claims.mjs` 即知每条引文是否逐字属实。
本版 96 条引文全绿（0 失败）。这是新工程与旧工程的根本区别——经证从「写上去的」变成「钉上去的」。

**定位性质四分**（每节点必标其一）：

| 类型 | 含义 | 例 |
|---|---|---|
| scripture | 经论明文所述空间位置 | 须弥山、琰魔王国（洲下五百） |
| nonspatial | 经明言无方所，不可物理定位 | 无色界（「都無有處」）、四圣 |
| doctrine | 义理总纲，非地图一处 | 十法界总纲、高程之则 |
| schematic | 教学示意【今设】 | （本版未用，留给后续） |

**异说并录**：须弥高度（俱舍八万踰缮那／起世八万四千由旬）、地狱方位（俱舍洲下二万／
世记经两金刚山间）、色界处数（十七处／迦湿弥罗十六处）——不裁断、不调和，两说都给原文。

## 三、美术方向（重新思考后的定案）

**立轴长卷**：世界地图的正形是一幅可滚动的纵剖立轴——下起风轮、上至色究竟，
这本身就是汉传佛教「诸天图解」的传统图式；藏经洞夜空（深靛青）为底，敦煌矿物色系着色：

| 域 | 色 |
|---|---|
| 三轮 | 靛青（风/水）· 土金（金轮） |
| 幽冥 | 烟炱、深赭（克制，不渲染恐怖） |
| 海洲 | 石青海、土红南洲、泥金七金山 |
| 诸天 | 石青渐淡向上、泥金点睛 |
| 非方所栏 | 淡紫灰虚线（明示教学【今设】） |
| 净土 | 石绿 + 莲白 + 泥金横超光路 |
| 佛法界 | 纯金光柱，不作形像 |

3D 不是第一步：先把二维立轴的**权威模型**立稳（数据即地图），3D 行走版之后读同一份 world.json。

## 四、交互设计

1. **滚动即升沉**：纵向滚动走完从无间狱到色究竟的竖轴——身体先于文字感知「竖出三界」之高远；
2. **横超在横轴**：西方极乐不挂竖轴，在画面西侧，以金色光路相连——「竖出难、横超易」成为空间语法；
3. **点击即经证**：任一节点弹出经证卡：界属／定位性质／经说量度／今注（白话，明标非经文）／
   逐字引文（「已核·逐字」徽标）＋《典籍》卷品＋页行号直链 CBETA 在线阅读器；
4. **诚实的比例尺**：页首明示「图为示意非等比」，经说数值随原文给出，不伪造等比空间。
