# 须弥山十法界 · 世界地图模型

> 独立重构工程（2026-07-18 立项）。前身《十法界须弥山世界》（makeplay v42 复刻）推倒重来：
> **一切结构以 CBETA 经典原文为准**，旧工程三份文档（经证总表／垂直分层设计书／系统论文）仅作检索线索，不作依据。

## 这是什么

一个「经证优先」的须弥山十法界世界模型：

1. **语料层** `cbeta/` —— CBETA 电子佛典纯文本（带页行号，底本取 lem、注文剔除），16 部典籍；
2. **模型层** `data/world.json` —— 世界地图数据：13 层域 · 38 节点 · 96 条逐字经证引文，每条带页行号；
3. **呈现层** `map/index.html` —— 交互式立轴纵剖地图（敦煌矿物色）：点任一处看逐字经证卡，直链 CBETA。

## 铁律（不可违背）

- 引文必须是语料的**逐字连续子串**，由 `verify-claims.mjs` 机器核证，行号必须一致——核不过不得标 verified；
- 经论**异说如实并录**（须弥高度、地狱方位等），不强行调和；
- 无色界、四圣经明言**无方所**者，只入「非方所栏」，不作物理定位；
- 白话导读（summary／今注）与经文严格分离；一切示意安排标【今设】；
- 佛不作形像，以光表德；地图为示意非等比，经说数值随节点原文呈现。

## 常用命令

```bash
# 经证逐字核证（改动 data/world.json 后必跑；全绿才算数）
node scripts/verify-claims.mjs          # 只查
node scripts/verify-claims.mjs --fix    # 行号按实测回写（引文本身必须已逐字命中）

# 由数据同源生成《世界志·经证辑要》
node scripts/gen-gazetteer.mjs

# 新增典籍：下载 CBETA XML 后转带行号纯文本
node scripts/xml2text.mjs cbeta/xml/T01n0001.xml T0001

# 本地查看地图
python3 -m http.server 5941 --directory .
# 浏览器打开 http://localhost:5941/map/
```

