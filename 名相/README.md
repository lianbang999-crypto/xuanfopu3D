## 呈現體例（2026-08-03 發起人定）

**原文在前，出處在後（小字）。越簡單越好。** 不分欄、不加標籤、不加「【辭典】【譜內】」之類。

```

                          丁福保《佛學大辭典》· 見思
```

## 舊詞條庫一律降為參考

`hub.json` 之 291 條 `gloss` **未經審核，混入通途教理而未對齊譜文**。實例：

> 舊 def：「見惑——身見、邊見、邪見、見取、戒禁取等」
> 譜內原文：「那表屬見煩惱。亦名分別惑。亦名見惑。**（邪見分別所起惑故。）**」

五利使那一套是通途教理，**譜裡沒說**。「散善」更明顯——譜中從來只與「定善」對舉使用，根本無專釋，舊 def「散心中所修的善」是外來的。

故舊 def 不作正文，只存 `legacy` 欄留檔（將來若證某條實對，仍可回查其當初說法）。

## 轉指須人工核——自動跟進會出錯

辭典中 18 條為「見○○條」式轉指，逐條核後：**15 條可用，3 條不可**。

| 不可用 | 何故 |
|---|---|
| 一生補處 | 轉指「彌勒」——**通義轉成了特指**，一生補處是等覺通稱，非專指彌勒 |
| 四諦 | 轉指「四字部四諦條」，即指自身，解不開 |
| 斯陀含 | 轉指「四向及四果條」，辭典未收此目 |

此三條改從譜內取。**這正是不可全交機器之處**：自動跟進轉指會把「一生補處」誤釋為彌勒。

## 校驗（build.mjs，皆須零）

| | |
|---|---|
| ① 辭典條可尋 | `k` 所指之詞條須存在於丁福保原檔，且其釋義非轉指 |
| ② 譜內條逐字 | 錨句須在所繫塊之原文中逐字尋得（同全文錄入之錨句法） |
| ③ 出處可核 | 譜內條之卷次行號須與 `全文/corpus.json` 相符 |
| ④ 無自撰 | 釋義正文須全等於來源（辭典原文或譜內原文），一字不改 |

第 ④ 條最要緊：**釋義不是我們寫的**，所以可以逐字校。凡校不過者，即是有人動了手。
