那謨二字只有②一层；变的是阿彌陀佛四字，③与④择一当令，**判准在去向**：去向仍在世间或本教内次第升进者取③，去向跨藏通别圆者取④。谱主自注为证：「阿佛依**生滅門**…彌佛依**無生門**…陀佛於**次第門**…佛佛於**圓頓門**」（第一门四无色定位）。

## 三、形制定则（一切条文统一遵守）

1. **不用行内术语**——「本位行法列此组」「出X门而入Y门」一律不写，去向直接白话说。
2. **先说这个位是什么**，一句话，用谱曰的意思而非谱曰的字面。
3. **再说两个字在这里各表什么**——取本门当令的那一层义。
4. **末句说去向与所以然**，因果连着说。
5. 引经有据但轻说，「经中说」「谱主说」即可，不堆书名卷次。
6. 红线：不冠「譜曰」、不署蕅益大師；界面另栏署「字义解」。谱主已有按语处一律不覆盖。

## 第三门 四種惡趣門（已核，已写 28 条）

**定谳**

| 字 | 本门实指 |
|---|---|
| 那 | **见惑种子**，非现行分别惑 |
| 謨 | 爱惑，能润生不能发业 |
| 阿彌陀 | 施戒定散善，随宿善力招异熟果 |
| 佛 | **仍是卷首定诠的无漏善慧，不改**。本门之别在现起方式与所得果，非字义 |

「那」改判有谱曰六处明文：阿鼻「劇苦之中，見思無由起於現行」／下品畜生「見惑不行，縱有思惑但能潤生不能發業」／中品畜生「不現起分別見惑…而由**見種**及思惑力」／無財鬼「不起見惑故**不行那**」／少財鬼「由**見種**及現思力」／有財鬼「雖不起分別惑而那那墮無間者」。

> **用词定则：作「见惑种子」，不可作「见惑习气」。** 谱主用词严整——「見種」四见（中品畜生、少財鬼、第五门廣果天「見種未斷」、第七门念清淨戒「見種猶未斷」），指惑体**未断**而此时不现行；「習氣／餘習」则一律在**正使已断之后**（「既斷正使，又侵餘習」「頓斷正使習氣俱盡」「達緣起無生，兼侵習氣」「誓扶習氣，受三界身」「見理分明，習氣微薄」），是二乘侵而不尽、唯佛能断的余分。二者所指恰相反：恶趣众生见惑分毫未损，只是苦逼痴暗不能现起；若称「习气」，便成已断正使的圣位，与实情颠倒。

「佛」字**不改判**。本门之别在现起方式与所得果：恶趣众生自力发不起无漏慧，须仗佛力与性善力激发——阿鼻「阿佛等三，雖**仗佛力**，及**性善力**，得出劇苦」／無間「那佛等五，雖**仗佛性威力**」；所得果止于出苦、听法、护法、生天（阿鼻佛佛「往昔所熏佛乘種子，今日觸佛慈光」／下品畜生「如蜘蛛聽誦金剛經等」／上品畜生「由福德力…故遇佛佛便為護法八部」），不入四教位次。此是果相，非字义。

> **勘误（2026-08-08）**：初稿判「佛＝佛力接引·听法之缘，**非**证位无漏慧」，偏。一则以果改字义，与「阿＝创证」同病；二则谱曰是「仗佛力，**及性善力**」两力并举，说「非无漏慧」便抹去性善力一半——恶趣众生的无漏善种并未断灭，只是自力不发；三则「仗佛力」是**全谱通例**（第一门「那佛，仗佛慈光，為初禪主」、「雖具煩惱，仗佛神力，得為初禪二禪天王」、「謨佛，仗佛慈力，不墮四趣」），凡惑业未除而得佛字者皆然，不足以作一门之改判。第三门 28 条条文本作「佛表智慧」，即卷首定诠，无须改动。
> 教训入判准：**通例不可充作别解**——某说若在多门皆见，即是全谱通例，不得据以改某一门的字义。

**本门无四门义位。** 旧生成条把畜脩羅·鬼脩羅的那那、那謨解作「邪见分别所起，见真谛道时顿断」，与本门「见惑不现行」相违，已改。

**缺口二位**：畜脩羅、鬼脩羅各 14 组。谱曰于此二位只引《大佛顶经》辨其趣属（一因湿气有、畜生趣摄；一从卵而生、鬼趣所摄，以护法力乘通入空），未逐组解。其余 11 位或逐组详解，或以「餘皆例前可知」「餘同前釋」「餘亦如前」承前，皆已覆盖。

## 第五门 色無色天門（已核，待写 64 条）

**本门是「定地」**——「同屬天趣，同名**定地**，故合為一門」。

| 字 | 本门实指 | 谱曰 |
|---|---|---|
| 那 | 退起**下地**惑染（所退之地随本位而异） | 廣果天「那那生梵眾者，**退起初禪染**故…那謨生少光者，退起二禪染故；謨謨生少淨者，退起三禪染故」 |
| 謨 | 染著禅味而退 | 少光天「謨謨，**染著禪味**，退生初禪」 |
| 阿彌陀 | **仍是卷首定诠的施善·戒善·定善，不改**。在色界，此三善所资者是禅力；善力浅深不同，故所生之天有高下——与第七门「隨力淺深，漸成增上」同理 | 無想天「**阿阿等施戒禪定**，彼天總不能修，又彼壽長，故皆不行」；空無邊處天「唯耽暗定，故**阿阿等三不行**」 |
| 佛 | 无漏慧，出定地入圣位 | — |

> **勘误（2026-08-08）**：初稿曾判「阿＝创证／彌＝数修／陀＝深入兼四无量心」，**误**。谱曰「梵眾創得初禪，禪力未深」「梵輔數數修習」「大梵兼修四無量心」，说的是**每一天本位的品级**——天位高下由禅力浅深分，那是果的分类；六字是因，仍是施戒定。谱主在本门内即以「施戒禪定」称阿阿等六组，是直接反证。已改正 27 条（光音 6、無量淨 6、徧淨 6、福生 5、廣果 4）。
> 教训入判准：谱曰对**位**的描述与对**字**的定义须严分，不可以前者充后者。

**X佛组取④四门义**（前三教递进，第四落净土）——梵眾天为母句：「阿佛則見**生滅**理，便得不還（藏三果）／彌佛則悟**無生門**，成離欲地（通）／陀佛則真諦先明，准位應同五住（别）／佛佛則慈尊授手，剎那便悟佛乘（上品上生）」，其余十一天「餘如前說」承之。

**三类例外**：五不还天取杂修静虑品级（下品→中品→上品→上勝品→上極品），色究竟天特出「阿佛辟支佛地，彌佛菩薩地者，即便迴心入大乘故；佛佛通教佛地」；無想天为外道邪定所感，X佛组是堕后转生人道闻法；四空天仍取四门义（「彌佛忽悟即空，故成**衍門**離欲」），非想非非想「居三有極頂，更無可進，故阿陀等不行」。

**旧生成条仍须全部重写**，但缘由不是③层义用错，而是它一律缀「无慧导则属有漏」而不及本门实况——色界天人早已离欲，施戒定三善在此所资的是禅力、所感的是更高一地之天，与欲界求福报不同；且那謨二字在本门专表退起下地惑染与染著禅味，旧条泛作「见烦恼重叠／爱烦恼重叠」，亦不合本门。

## 第六门 生善滅惡門（已核，无待写）

谱曰开门定调：「聽法、護法、請法，令六道凡夫生出世善；作法、取相、無生三懺，令三障重罪皆得滅除，故為**入佛法之初門**」。故本门六字普遍指向四教法门的入处，不表人天善恶。**四门义在五位中前移到非「X佛」组**：

| 位 | 六字实指 |
|---|---|
| 聽法雜眾 | 唯一保持常例：「若生世間有漏善根，即感人天樂報，如阿阿至陀陀；若生出世無漏善根，即解**三乘四教**，如那佛至佛佛」 |
| 護法八部 | 前移：阿阿初果（藏）·阿彌见地·彌彌薄地（通）·阿陀初住·彌陀七住·陀陀十住（别） |
| 請法梵王 | 前移，谱曰点门名：阿陀「**無量門**中」→别五住／陀陀「**三昧門**中」→别十行 |
| 取相懺 | 前移：阿阿四念处（藏）／彌彌「接彼**相似空性**法流」（通性地）／阿陀等三「仰信**中道**」（别） |
| 無生懺 | 前移，谱曰直标四教：「所觀無生，**通乎四教**——或因緣生滅…或因緣即空…或因緣即假…或因緣即中」；继言「阿阿則**生滅門中**創發…」 |
| 作法懺 | 例外，取③义：阿阿至陀陀感人天，末组转忏法与戒品次第 |

## 第七门 增上戒學門（已核，已写 67 条）

总说：「因戒生定，因定發慧，斯則名為三無漏學，故學道人以戒為首。此戒**從小階大，從淺階深**，圓攝諸法，故名增上。」十三位即戒品阶次——小乘七众戒学八位（在家五戒→八关斋戒→沙弥十戒→持比丘律→持二部律→广持毗尼→住毗尼而不动→善能灭诤），大乘五支净戒五位（业→余→觉→念→无上道戒）。

**定谳**

| 字 | 本门实指 | 谱曰 |
|---|---|---|
| 那 | 毁犯与退堕 | 在家五戒「那那則必有毀犯，故須作法懺除」 |
| 謨 | 爱染舍戒或异熟果尽 | 沙彌十戒「謨謨則愛染偏強，退求寂以歸俗」；持比丘律「煩惱力強，不敢破戒，故捨具戒為優婆塞」 |
| 阿彌陀 | 仍是卷首定诠的施·戒·定，**以其力资戒品增上**，六组依次升进一至五阶 | 在家五戒「**阿阿等六，隨力淺深，漸成增上**」——此句是逐组判词，所指正是六个轮相组合。何以有浅深？卷首「**善則先小而後大**」，故施浅、戒中、定深 |
| 佛 | 遇佛则**开小成大** | 住毗尼「阿佛念清淨戒者，**開小成大**故」；在家五戒「那佛則五停以調見，謨佛則乾慧以治思，阿佛則成菩薩居士…彌佛則為菩薩比丘…陀佛則准十六觀經而生淨土，佛佛則悟戒之實相而淨六根」 |

**本门无四门义位。** 六字未另立新义，只是所资之处在戒品：升进阶数逐位可验——在家五戒位阿阿→八关斋戒（＋1）、阿彌→沙弥十戒（＋2）、彌彌与阿陀→持比丘律（＋3）、彌陀→持二部律（＋4）、陀陀→广持毗尼（＋5），八关斋戒、持比丘律、持二部律三位同此级差；广持毗尼以上因小乘戒学已到顶（善能灭诤第八位），故转入定学。

戒学既满转入定学有谱曰明文：善能灭诤「阿阿等**如次入於增上定學**」；持比丘律释陀陀去十一切处观曰「**由增上戒學，成增上定學**故」——这是解释因戒生定的转门，不是给「陀」字另下定义。故上位诸组去向多是十一切处观、九次第定、师子奋迅三昧、超越三昧等观炼熏修四种禅。

缺口 6 位：八關齋戒 15、持比丘律 13、持二部律 14、廣持毗尼 13、住毗尼而不動 6、覺清淨戒 6。谱曰于此六位或只释戒相与少数组（如广持毗尼只释謨謨、佛佛），余组承前例。
