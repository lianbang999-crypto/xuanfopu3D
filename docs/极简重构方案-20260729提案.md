## 一 · 设计再思考（三条主张）

### 1. 色彩立宪：从「色不过三」到 token 层

「色不过三」只写在纸上，`:root` 里只有字体变量、没有一个色 token（colors-1）——
散点色必然回潮：现状 152 个 hex + 204 个 rgba；金系一族就有三个 rgba 基座
（215,170,69 / 232,199,102 / 216,197,139）共 50+ 档透明度（colors-7）；
net.js 整套次要文字用蓝灰 #9aa3b5 引入第四色族（colors-3）；
红赭系 13 个互不相同（colors-4）；青系 9 个变体（colors-6）。

**立七个 token，全站唯一取色处**：

```css
:root{
  --gold:      #d7aa45;                /* 结构线·强调·金字（#d8ac47 等近似值全部归此）*/
  --gold-deep: #b0831c;                /* 主钮渐变深端，唯一保留处 */
  --gold-hi:   rgba(232,199,102,1);    /* 辉光/hover 亮态基座（语义一致，保留）*/
  --paper:     #efe0b4;                /* 正文 */
  --note:      #9d9170;                /* 次文/注脚（net.js #9aa3b5 蓝灰族并入此）*/
  --teal:      #96e1d6;                /* 联机/提示专用（#b9f0e6/#9cc3b2 等九变体归并）*/
  --woe:       #b05a42;                /* 恶趣语义色：仅限「惡↓」小字与珠色，禁作边框/底色 */
}
```

- 明度分层一律用透明度档（.06/.15/.28/.42/.7），不再新造 hex；
- 216,197,139 基座并入 --gold 透明档（联机面板由微冷转微暖，属预期，改后对照截图核一遍）；
- 转场星流粒子色、法界珠色/门色（realmHue）、轮面原字属数据/瞬态豁免，不入违例（核验组裁定）。

**一屏一枚金主钮**：每卡至多一枚实心金渐变钮（去向钮）；其余降为描边幽灵钮。
现状「问」卡两金并列（问 + 回到局中）、判词卡与掷轮钮同亮。主钮渐变端点归 token
（#d8ac47→--gold 消近重复），实心主钮作视觉锚点的既成设计保留（核验组 A 案）。

### 2. 行动线与浮层秩序：判词期一屏一事

- 判词在场时打开菜单/问成三层叠置（overlays-4）：开浮层前判词先自动收为既有 `.min` 签，关层还原。
- 浮层在场时顶栏「大厅/我的」看得见点不动，点击被 overlay 背景吃掉＝关层（overlays-5）——
  这是手机上「我的打不开」错觉的真因。二选一：浮层期两钮压暗 `pointer-events:none`（同时断 Tab 可达），
  或把两钮层级提到 overlay 之上、点击＝先关层再去所点之处（推荐后者，少一次点击）。
- 「我的」四个子页返程断链（overlays-3 / flow-3）：设置/六卷原文/行谱见闻 关闭后落裸场景，
  唯改名号会回「我的」——统一走已修好的「同路往返」模式。
- 状态行与判词自相矛盾（flow-1）：判词在场仍写「未起行 · 先掷發始因地」。
  在 showVerdict 的 `verdictFn = fn` 之后与 cancelVerdict 各补一次 sfpStatus()；
  轮相小牌题头「上一掷」在判词期改「本掷」。
- 判词卡「行 ▸」与掷轮钮同题同亮：**v360 有意设计（按掷钮＝先落子再起新掷），行为不动**；
  可选润饰＝判词期掷轮钮降为幽灵态（同一动作，视觉只留一枚主钮）。
- 「巨轮悬场中遮须弥山」经核验为**无头截图假象**（实际 0.23–0.47 秒瞬态，flow-9 驳回性结论），不改。

### 3. 标签三级制补执行 + 全屏页一根轴

标签层级语言（胶囊>幽灵字>族名）不变，补执行：

- **接线**：「同族同进退」距离门是死代码——auxFamOK 算完从未使用（labels-2），接上即可解山腰拥挤；
  接线时须同修简繁失配（av 存 zh() 前原名再查 FAM_OF，否则繁体模式族门失效）。
- **避让补盲**：辅标不查节点标签矩形（labels-3，「增长天王」连排进「七金山与七香水海」）；
  两侧竖杆（右天梯/左探底）与顶底栏未列入避让区、贴边阈值仅 2px（labels-4）——
  把 #ladder/#tierDots/#secWrap 可见者的 getBoundingClientRect 直接 push 进避让矩形集。
- **去杂色**：T1 界名标签 2px 界色底线（红/绿青/石青/淡金四色）整段删除（labels-1）；
  界色留给珠色与「名前 6px 色点」（规范明文允许）。标签文字色六种近似米金收敛为
  --paper + 透明度四档（labels-6）。
- **天梯可读性**：门号无底衬，窄屏下段淹没在亮金光带、「十一」被轨道虚线贯穿（labels-5）——
  .ladDoor b 与 #ladTop/#ladBot 加四向暗晕 text-shadow（与 .nlabel.far 同法）。

全屏页（大厅/动态/我的）**一根内容轴**：动态页现「标题贴左 1180 壳 + 列表 560 居中」两轴并存
（pages-3）——fsShell 收窄与 fsWrap 同轴；.pzTop 的 padding-right 用作用域规则处理，勿动大厅共用规则。
大厅顶条条目加 gap:18px（pages-1）；窄屏模式卡动作词「开始/随喜入座」升格为真按钮样式（pages-2，
字号走 var(--fs-md)）；640px 断点勿把承载数据的 .pzEyebrow 一并藏掉（pages-6）。
