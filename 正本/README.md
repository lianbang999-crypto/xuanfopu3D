# 白话正本 · 體例

本项目把《選佛譜》二百二十位按二十一相展开为四六二〇格，逐格一句白话，讲给用户听。须知第十五门原文不列轮相行法表；该门二十一格只是母本为保持矩形结构而设的终局占位，并非原谱另有二十一条规则。

本目录是**重起的一套**，与既有的 `src/sfp-doorN-why.js`（手工层）、`src/sfp-glyph-canon.js`（字义解）
并行不悖，各写各的。十五门全部写完之后再一并接入上屏，中途不动现有链路。

## 一 · 每一句要答的三件事

1. **这两个字表什么** —— 依卷首〈輪相表法第一〉六字定诠，取该门该位当令的那一层。
2. **为什么是这个结果** —— 谱主给了理由的用谱主的理由；未给的依本门内证推得。
3. **结果本身是什么** —— 位名若是生僻名相（无想天、鬼修罗、取相忏、乾慧地），一并讲明白。

### ④ 四門的定诠出处（谱主自下，散在他门，写时必查）

四门即四教，其骨架是**四种四弘誓愿**（＝四种四谛）：

| 門 | 字 | 四弘 | 教 | 观法／位次 |
|---|---|---|---|---|
| 生滅門 | 阿 | 生滅四弘 | 藏 | 事度心・煖位 |
| 無生滅門 | 彌 | 無生四弘 | 通 | 體空觀・乾慧地・性地 |
| 次第門 | 陀 | 無量四弘 | 別 | 次第三觀 |
| 圓頓門 | 佛 | 無作四弘 | 圓 | 圓頓妙觀（一心三觀） |

- **四弘配四门**：第一门世間福位「阿佛事度心者。依生滅門。能發四弘誓願故。彌佛體空觀者。
  四弘誓願。依無生門發故。陀佛次第觀者。能發無量四弘誓故。佛佛圓頓觀者。能發無作四弘誓故。」
  第四门南贍部洲位再出一次，字更全（生滅四弘／無生四弘／無量四弘／無作四弘）。
- **乾慧地**：第十一门初乾慧地位「觀身受心法。悉皆如幻如夢。雖未得煖法相似理水。
  而智慧深利。故名乾慧。乃外凡觀行位也。」——所欠是**相似理水**，非定水；其慧本自深利。
- **性地**：第十一门二性地位「無生理觀。能發煖等四種善根。得相似無漏性水。故名性地。
  乃內凡似解位也。」——「性水」是**相似無漏性水**，由**無生理觀**发四善根而得。
- **次第三觀（別）**：第十二门「行人先信中道佛性。然後次第修行三觀以剋證之……
  理則隔歷三諦。智則三智次第。斷則三惑前後……位不相收……不相融攝也。」
  ——「次第」是**隔歷不融**之专名，不是「有先后」的泛称。
- **圓頓妙觀（圓）**：第九门圓頓妙觀位「亦名一心三觀……苦即法身。惑即般若。業即解脫……
  隨其所觀諸境。了知當體即空假中。」第十三门「三諦圓融……三一相即……當下圓成。體非漸證。」

**「漸」与「即」是一对**：別教漸（隔歷），圓教即（相即）。谱主凡在末二组用此二字对举处，
即是别圆之判，写时须并出对照，不可拆开各讲各的。

## 二·五 · 前置定诠查证（2026-08-08 立，写每一门之前必做）

`正本/定诠索引.md` 收全谱 **220 位**各自的本位譜曰定义段，注明卷·行号。

**规矩：凡一格的去处名相，先在索引里查该位自己的定诠，用谱主的话；查不到才用通义，并注明。**
此规矩因门一门二两次误读而立——「性水」「次第」「即」「上品畜」「人脩羅」等词，
谱主都在别门下过定诠，而我在前门先按常识写掉了。谱主自己定过的，不许我另说。

索引由 `校正原本/原文/B0136_00N.txt` 机器抽取；位名超长者（十向二位）与第十五门终位
（「佛」，无轮相）需人工补入，已补。

## 三 · 写法定则

- **大白话**。给用户看，不给同行看。不用「本位行法」「此组列出」「准知」之类的工程语。
- **先点字义，再讲所以然**。开头即说这两个字表什么，读者一眼知道自己掷出的是什么。
- **名相随手讲明，并以本谱定诠为准**。「无财鬼」要说「受形恶劣，纯苦无乐」；
  「取相忏」要说「立坛结界、六时勤修五悔，求诸佛菩萨冥显加被而灭根本重罪」。不留生词给用户自己查。
- **谱主有话，用谱主的话**；谱主未言而由本门内证推得者，直陈缘由，不加「谱中未明说」之类免责句。
- **不冠「譜曰」，不署蕅益大師**。本层是本项目的白话，界面另栏署名，不与原文冒充。
- 引文以 `‖` 分隔挂在句尾，读者可点开对照原文。
